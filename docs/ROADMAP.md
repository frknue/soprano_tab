# Roadmap

Soprano Tab copies AltTab's full feature set. What is left out, and why, is listed below,
followed by ideas beyond AltTab that are not built.

## Not copied (family conventions)

- Preferences window: `~/.config/soprano-tab/settings.json`, live reloaded, opened from
  the menu bar item.
- Sparkle updates and crash reports: install with `scripts/install.sh`.
- The Pro license.
- 21 UI languages: the family's UI is English.

## Later

- Soprano panes and tabs as switcher items next to windows.
- A Soprano `⌃A` command that opens the switcher.
- Notarized releases and a Homebrew cask, like Soprano's.
